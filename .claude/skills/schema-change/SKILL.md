# スキーマの変更手順

1. **理由をはっきりさせる**：どの頁のどの情報が今のスキーマで表せないのか、用途（質問応答・差分チェック・PLCプログラムとの突き合わせ）のどれに効くのかを書く。
2. `schema/page.schema.json` を直し、`$id` と `properties.schema_version.const` の版を上げる。
   - 互換のある追加（任意の項目を足す）：小さい版を上げる（0.1 → 0.2）。
   - 既存の項目の意味や必須を変える：大きく扱い、移行を必ず行う。
3. `schema/CHANGELOG.md` に、日付・版・変更点・理由・影響する正解データを書く。
4. 既存の `ground_truth/**/*.json` を新しい版に合わせて直し、`schema_version` を更新する。保存時にフックが検証するので、エラーがなくなるまで直す。`reviewed` の正解の**中身の判断を変える**ときは、ユーザーに確認してもらう。
5. AIへの指示（プロンプト）や評価のコードがスキーマに依存している場合は、合わせて直す。
6. 仕様に関わる変更なら docs/SPEC.md §6 も更新する。
